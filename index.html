Cómo crear y configurar un punto de venta CAEA

Instructivo Núcleo Check

Adherirte y crear un punto de venta CAEA te permite seguir facturando en caso de que tu punto de venta principal no pueda completar la operación por fallas de conectividad con ARCA o problemas similares.

1. Crear el punto de venta CAEA en ARCA

El punto de venta CAEA se crea de la misma forma que un punto de venta convencional:

  1. Ingresá a ARCA con tu CUIT y clave fiscal.
  2. Entrá al servicio Administración de puntos de venta y domicilios.
  3. Seleccioná la empresa o contribuyente con el que vas a operar.
  4. Hacé clic en A/B/M de Puntos de venta / emisión y luego en Agregar.

Se abre la ventana Alta de Punto de Venta / Emisión:

Completá los datos de la siguiente forma:

Número de punto de venta
Tiene que ser distinto a los que ya hayas creado.
Nombre de fantasía
Podés escribir el que quieras, ya que solo es visible para ARCA. Te recomendamos Núcleo Check CAEA.
Dominio asociado
Podés dejarlo vacío o escribir el dominio de tu sitio web o tienda online (por ejemplo, mitienda.com.ar).
Domicilio
Seleccioná el domicilio que corresponda al punto de venta.
Sistema
Elegí la opción CAEA que aparezca según tu condición tributaria. Por ejemplo, para Monotributo: CAEA - Fact. Elect. (RECE) - Monotributo - Contingencias.

Al terminar, presioná Aceptar.

2. Configurar el punto de venta CAEA en Núcleo Check

Una vez creado el punto de venta en ARCA, tenés que cargarlo en el sistema:

  1. Ingresá a Núcleo Check.
  2. Andá a Configuración → Facturación.
  3. En la sección Facturación, completá el campo Punto de venta CAEA con el número que creaste en ARCA (por ejemplo, 90001).
  4. Presioná Guardar y salir.
Importante:
  • El punto de venta CAEA tiene que ser distinto al punto de venta CAE (el que figura en el campo Punto de venta).
  • Si tenés varias sucursales, cada una debe usar un punto de venta CAEA diferente (90001, 90002, etc.).
  • El sistema usa este punto de venta solo cuando ARCA no responde. En condiciones normales se sigue facturando con el punto de venta CAE.
